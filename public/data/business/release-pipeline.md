## 1. Release Types Matrix

Each release type has different legal requirements, lead times, and distribution paths. Know which lane you're in before you start.

### 🎵 Original Track (Single)

| Phase | Task | Owner |
|-------|------|-------|
| Production | Final mix + master to -1 dBTP, LUFS -14 streaming | Eric |
| Registration | Register with ASCAP/BMI; obtain ISRC | Eric |
| Metadata | BPM, key, genre, mood, ISRC, UPC | Eric / Distributor |
| Artwork | 3000×3000px JPG, RGB, <10MB | Eric / Designer |
| Distribution | DistroKid / TuneCore → all DSPs | Distributor |
| Beatport | Submit 6+ weeks early for New Releases editorial | Eric |
| Promo | Promo pool, playlist pitch, social teasers | Eric / AI Agent |
| Release | Friday drop (Spotify/Apple alignment) | Distributor |

**Lead time:** 8–12 weeks (Beatport consideration requires 6 weeks minimum)

**Legal gate:** Full copyright ownership — no sample clearance needed, or samples cleared before submission.

### 🗂️ EP (3–6 Tracks)

| Phase | Task | Owner |
|-------|------|-------|
| Production | All tracks mixed/mastered, sequenced with intentional flow | Eric |
| Registration | Individual ISRCs per track + UPC for release | Eric / PRO |
| Concept | Title, artwork concept, track order, narrative thread | Eric |
| Artwork | Main cover + individual track art (optional for DSPs) | Designer |
| Pre-save | Set up pre-save link via Feature.fm or ToneDen 4 weeks out | Eric / AI Agent |
| Distribution | DistroKid / TuneCore | Distributor |
| Lead single | Release 1 track 2–3 weeks before EP drop | Eric |
| Press | Press release + music blog outreach | Eric / AI Agent |
| Release | Friday drop | Distributor |

**Lead time:** 10–14 weeks

**Notes:** Lead single strategy is critical — gives playlists/press something to latch onto before the full EP lands.

### 💿 Album / Compilation

| Phase | Task | Owner |
|-------|------|-------|
| Production | 8–18 tracks, mastered for cohesion, DDP or WAV delivery | Eric |
| Registration | ISRCs per track, UPC, copyright registration (eCO) | Eric / PRO / Copyright Office |
| Strategy | Release sequencing: 2–3 singles before album, staggered 3–4 weeks apart | Eric |
| Artwork | Full package: front/back/spine, digital booklet (PDF), liner notes | Designer |
| Pre-order | Set up 4–8 weeks out on iTunes pre-order | Eric / Distributor |
| Press | Full EPK, long-lead press (magazines, blogs) 8 weeks out | Eric |
| Radio | Radio promo — DJ pools, SiriusXM, satellite | Eric |
| Release | Friday drop across all DSPs | Distributor |

**Lead time:** 16–20 weeks

**Notes:** Compilations involving other artists require individual contributor agreements and split-sheet documentation before distribution.

### 🔄 Official Remix

| Phase | Task | Owner |
|-------|------|-------|
| Legal | Signed remix agreement from original rights holder BEFORE any distribution | Eric + Label/Artist |
| Stems | Receive stems/multitracks from original artist | Original Artist |
| Production | Remix, mix, master | Eric |
| Metadata | Credit: "Original Artist — Track Title (ANIMAL Remix)" | Eric |
| ISRC | New ISRC assigned to remix | Eric / Distributor |
| Royalties | Agree on split: mechanical, master, performance splits in writing | Eric + Rights Holder |
| Distribution | Route through label or self-distribute (depends on agreement terms) | Distributor / Label |
| Promo | Coordinate with original artist for cross-promotion | Eric |

**Lead time:** 8–12 weeks (gate: remix agreement signed)

**Legal gate:** ⚠️ NO distribution without a written remix agreement. This is non-negotiable. Verbal approval is not enough.

### 🎚️ Mashup / Edit

| Phase | Task | Owner |
|-------|------|-------|
| Legal review | Assess: Bootleg/promo only vs. commercial release | Eric |
| Bootleg path | Upload to SoundCloud (free), DJ promo only — do NOT distribute to DSPs | Eric |
| Commercial path | Requires clearance from ALL sampled masters + compositions | Eric + Music Attorney |
| Clearance | Contact publisher (composition) + label (master) for each sample | Eric / Attorney |
| Metadata | Tag all source material clearly | Eric |
| Distribution | Only after all clearances secured in writing | Distributor |
| Promo | Promo pool, SoundCloud free download, DJ community | Eric |

**Lead time:** Bootleg = immediate. Commercial = 3–6+ months for clearances.

**Notes:** Most mashups stay in the promo/bootleg lane. That's industry standard. Don't risk takedowns by uploading uncleared commercial releases to DSPs.

### 📻 DJ Mix / Podcast Episode

| Phase | Task | Owner |
|-------|------|-------|
| Recording | Record mix (stereo WAV, 320kbps MP3 export) | Eric |
| Tracklist | Document every track: Artist — Title — Label — BPM | Eric |
| Licensing | Mixcloud has blanket licenses (preferred platform). SoundCloud = risk. | Platform |
| Upload | Mixcloud (licensed), podcast platforms via RSS feed | Eric / Distributor |
| Podcast RSS | Buzzsprout, Anchor, or Podbean for podcast distribution | Eric |
| Apple Podcasts | Submit RSS to Apple Podcasts Connect | Eric |
| Spotify Podcasts | Submit via Spotify for Podcasters | Eric |
| Artwork | 3000×3000px podcast cover art, 72dpi minimum | Eric / Designer |
| Metadata | Episode title, tracklist description, keywords | Eric / AI Agent |

**Lead time:** 1–2 weeks

**Notes:** DJ mixes cannot be monetized on DSPs due to unlicensed content. Stick to Mixcloud (licensed) and podcast platforms. DO NOT submit mixes to DistroKid/TuneCore — you'll get strikes.

### 🧰 Sample Pack / Stems

| Phase | Task | Owner |
|-------|------|-------|
| Production | Organize: loops, one-shots, stems by category and BPM/key | Eric |
| Originality check | Confirm 100% original content (no third-party samples embedded) | Eric |
| Metadata | BPM, key, genre, tempo, instrument tags per file | Eric |
| Packaging | ZIP folder structure: /Loops, /One-Shots, /Stems, /MIDI | Eric |
| Licensing | Royalty-free license agreement (standard Loopmasters-style) | Eric / Attorney |
| Platform | Loopmasters, Splice, ADSR | Eric |
| Promo | Tutorial video, producer community outreach, social teasers | Eric / AI Agent |

**Lead time:** 4–6 weeks

**Revenue model:** One-time purchase or Splice subscription revenue share.

### 🤝 Collaborative Release

| Phase | Task | Owner |
|-------|------|-------|
| Agreement | Written collaboration agreement: ownership splits, credit, approval rights | All Parties |
| Split sheet | Document contribution splits for master + composition | All Parties |
| Production | Coordinate production workflow, stem exchanges, approval rounds | Eric + Collaborator |
| Metadata | "ANIMAL & [Collaborator]" or "ANIMAL feat. [Artist]" — agree before submission | All Parties |
| Distribution | Designate single distributor; set revenue splits in distributor dashboard | Lead Artist |
| PRO registration | Each collaborator registers their share with their respective PRO | Each Party |
| Promo | Coordinate release timing, cross-posting, shared announcements | All Parties |

**Lead time:** 10–14 weeks (longer due to coordination overhead)

**Legal gate:** ⚠️ Split sheet and collaboration agreement BEFORE mixing starts. Retroactive agreements are messy.

## 3. Distribution Checklist

### 📋 Metadata Requirements (Every Release)

| Field | Requirement | Notes |
|-------|-------------|-------|
| Track Title | Exact title, correct capitalization | No special chars that break DSPs |
| Artist Name | Consistent across all releases | "ANIMAL" or "Eric ANIMAL Mills" — pick one and stick |
| Featured Artists | Credited in metadata AND title field per DSP norms | |
| ISRC | Required for all commercial releases | Assign per track, not per release |
| UPC | Required for album/EP/single as a bundle | Auto-assigned by most distributors |
| BPM | Exact BPM (or half/double for DSP display) | Beatport requires this |
| Key | Musical key (e.g., "A Minor", "F# Major") | Beatport/Traxsource require this |
| Genre | Primary + sub-genre | Be specific: "Electro House" not just "Electronic" |
| Mood | 2–3 mood descriptors | Helps editorial + algorithmic placement |
| Release Date | Friday (industry standard) | Exceptions for special releases |
| Label | Legal label name | Register label with distributors in advance |
| Copyright | "℗ [Year] [Label/Eric Mills]" | Year of first release |
| Publishing | "© [Year] [Publisher/Eric Mills]" | |
| Explicit | Flag accurately | False flags can get releases rejected |
| Language | English (or relevant language) | |

### 🎨 Artwork Specs

| Platform | Minimum Size | Format | Color Space | Max File Size |
|----------|--------------|--------|-------------|---------------|
| Spotify / Apple Music | 3000×3000px | JPG | RGB | 10MB |
| Beatport | 3000×3000px | JPG | RGB | 10MB |
| SoundCloud | 3000×3000px | JPG or PNG | RGB | 10MB |
| Podcast Cover | 3000×3000px | JPG or PNG | RGB | 512KB (Apple) |
| Social (IG Post) | 1080×1080px | JPG/PNG | RGB | 30MB |
| Social (IG Story) | 1080×1920px | JPG/PNG | RGB | 30MB |

**Hard rules:**
- ❌ No URLs or prices in artwork (Spotify will reject)
- ❌ No explicit drug use imagery
- ❌ No third-party logos without clearance
- ✅ Text in artwork: use a clean, readable font; avoid tiny text
- ✅ Export separate social crop versions from the same source file

## 6. Sync Licensing Pipeline

Sync is one of the highest-value revenue channels for independent artists. A single TV/film placement can outperform months of streaming revenue.

### 🎬 Step 1: Track Assessment

Before pitching any track for sync, evaluate:

| Question | Requirement |
|----------|-------------|
| Is it 100% cleared? | No uncleared samples. Period. |
| Do you control both master AND publishing? | (or do you have written permission from all rights holders?) |
| Does it have lyrics? | If yes, are they free of brand names, profanity (for certain markets), or dated references? |
| Instrumental version available? | Always deliver a clean instrumental. |
| Alternate edits available? | 30-sec, 60-sec, 2-min versions are standard requests. |

### 🎬 Step 2: Metadata for Sync

Sync supervisors search by keywords. Your metadata must be findable:

| Field | Example |
|-------|---------|
| Title | "Chrome Horizon" |
| BPM | 128 |
| Key | A Minor |
| Mood | Energetic, Triumphant, Driving |
| Instrumentation | Synthesizer, 808 bass, Drum machine, Vocal chop |
| Genre | Electro House, EDM |
| Themes | Speed, Night, Urban, Technology, Victory |
| Lyrical content | Instrumental / Clean vocals / Contains profanity |
| Versions available | Full, Instrumental, 30-sec, 60-sec, Underscore |
| Clearance status | Master: ANIMAL / Publishing: ANIMAL (or split) |

### 🎬 Step 3: Platform Submission

| Platform | Focus | Cost | Notes |
|----------|-------|------|-------|
| Musicbed | High-end commercial / brand | Free to submit; rev share | Curated; worth the application |
| Artlist | YouTube / online video | Annual license model | High volume, lower per-sync fees |
| Pond5 | Stock / broadcast / indie film | Free upload; 35–50% rev share | High volume platform |
| TAXI | A&R submission service | $299/yr membership | Real industry A&R feedback; film/TV |
| Musicosm | Film/TV | Revenue share | Boutique sync agent |
| Epidemic Sound | Online creators / YouTube | Flat fee buyout | Non-exclusive option |
| Soundsnap / AudioJungle | Broadcast / video | Per-license | Stock music model |
| Direct outreach | Film/TV supervisors | Free | Highest value, requires relationships |

### 🎬 Step 4: Music Supervisor Outreach

**How to find supervisors:**
- IMDbPro (paid): Search by project type; find supervisor credits
- Music Supervisor Directory (musicsupervision.com)
- LinkedIn: Search "music supervisor"
- Guild of Music Supervisors: guildofmusicsupervisors.com
- NARIP (narip.com): Networking events with supervisors

**Pitch format:**

> **Subject:** [Genre] [Mood] Music — Available for Sync // ANIMAL
>
> Hi [Name],
>
> I'm Eric "ANIMAL" Mills — DJ/producer with 25+ years, major label remix credits (Eminem, Snoop, Linkin Park via Crooklyn Clan), and a catalog built for high-energy sync applications.
>
> Attaching a few tracks I think could work for [specific show/project or genre]:
> - "Track Name" — 128 BPM, A Minor, Energetic/Driving [Spotify link or streaming preview]
> - "Track Name" — 140 BPM, D Minor, Intense/Action [link]
>
> All tracks are 100% cleared (I own master + publishing). Instrumental versions and alternate edits available on request.
>
> Happy to send a full catalog overview or custom edits for specific needs.
>

## 7. Release Calendar Template

### 📅 12-Month Release Calendar (2026)

**Philosophy:**
- 1–2 singles per month maximum (don't cannibalize your own releases)
- Space singles 3–4 weeks apart minimum
- 1 EP or album per quarter maximum
- Plan quiet months for production, heavy months for releases
- Align major releases with key industry events (WMC in March, ADE in October, holidays)

### Quarterly Strategy

| Quarter | Focus | Target Releases |
|---------|-------|-----------------|
| Q1 (Jan–Mar) | Year-opener energy + WMC timing | 2 singles + 1 EP (March for WMC) |
| Q2 (Apr–Jun) | Festival season build + summer | 2–3 singles (staggered) |
| Q3 (Jul–Sep) | Summer catalog + fall setup | 1–2 singles + possible album |
| Q4 (Oct–Dec) | ADE timing + year-end | 1–2 singles + holiday content |

### Month-by-Month Slots

| Month | Week 1–2 | Week 3–4 |
|-------|----------|----------|
| **JANUARY** | [Single Slot A] ← New Year energy | [Production / Prep] |
| **FEBRUARY** | [Single Slot B] | [EP Prep begins / Press outreach starts for March] |
| **MARCH** | [EP Release] ← WMC timing (Winter Music Conference, Miami) | [Post-EP promo / WMC appearances] |
| **APRIL** | [Production sprint] | [Single Slot C] |
| **MAY** | [Single Slot D] | [Prep for summer release] |
| **JUNE** | [Single Slot E] ← Summer opener | [Festival season promo / DJ set recordings] |
| **JULY** | [DJ Mix / Podcast drop] ← Summer mix | [Production] |
| **AUGUST** | [Single Slot F] | [Album/Compilation prep if planned] |
| **SEPTEMBER** | [Single Slot G] ← Fall re-entry | [Album pre-release setup if applicable] |
| **OCTOBER** | [Album Release OR Single Slot H] ← ADE timing | [ADE outreach / fall push] |
| **NOVEMBER** | [Single Slot I] | [Year-end prep / catalog push] |

### Key Industry Event Alignment

| Event | Date (approx.) | Release Strategy |
|-------|----------------|------------------|
| Winter Music Conference (WMC) | March, Miami | Release EP/single the week of WMC |
| Ultra Music Festival | March, Miami | Coordinate teaser content |
| EDC Las Vegas | May | Release upfront single with festival energy |
| Groove Cruise | Various | Coordinate with booking; release tied to set |
| Amsterdam Dance Event (ADE) | October, Amsterdam | Major release or announcement |

### Release Spacing Rules

✅ Minimum 3 weeks between any two releases  
✅ Minimum 6 weeks between a single and an EP that contains it  
✅ Minimum 8 weeks between an EP and an album  
❌ Never release on same Friday as a massive artist in your genre (check new release calendars)  
✅ Prefer low-competition Fridays (avoid Grammy week, major festival announcement weeks)
