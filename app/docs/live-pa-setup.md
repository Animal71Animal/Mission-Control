## Core Setup: Ableton + Push 2 Live PA

This is already a legit professional rig. Plenty of touring artists run this exact combo. Here's how to dial it in properly.

---

## 1. Ableton Session View — Your Stage

Live PA lives in **Session View**, not Arrangement. Think of it as a grid of infinite possibilities.

**Organize your set like this:**

| Column (Track) | What goes there |
|---|---|
| Drums / Beats | Drum Racks with your core patterns |
| Bass | Bass loops, synth basslines |
| Chords / Pads | Chord progressions, atmospheric pads |
| Melody / Lead | Hooks, leads, melodies |
| Vocals / Samples | Vocal chops, one-shots, FX hits |
| FX Bus | Returns: reverb, delay, effects chain |
| Master | Limiter, EQ, meters |

**Clip colors:** Color-code by energy level (green = low/intro, yellow = mid, red = peak/drop). You'll navigate by feel in the dark.

**Follow Actions:** Set clips to auto-advance — great for building tension without having to manually launch every loop.

---

## 2. Push 2 — Your Instrument

Push 2 is the hands-on brain of the setup. Key modes to master:

- **Session Mode:** Launch clips and scenes. Arm/disarm tracks. This is your main performance view.
- **Note Mode:** Play melodic parts live on the pads. Great for improvised solos, fills.
- **Drum Rack Mode:** Fire samples, one-shots, and drum patterns on the 4x4 pad grid.
- **Device Mode:** Twist knobs to control macros, filters, effects in real-time. Map your most-used parameters here.
- **Loop Mode:** Set and adjust loop start/end points on the fly.

**Key workflow: Macro Mapping**
Set up macro knobs on your main tracks mapped to:
- Filter cutoff (for DJ-style filtering)
- Reverb send
- Delay send
- Pitch/transpose
- Volume/Gain

You'll turn one knob on Push and the sound changes dramatically.

---

## 3. Looping Setup

For live looping into your set:

**Option A: Ableton Looper (recommended)**
- Drop a Looper device on a dedicated track
- Map record/overdub/play/clear to Push 2 buttons
- Layer up to 8 loops live — bass, melody, vocals, whatever
- Sync to master tempo automatically

**Option B: Clip recording in Session View**
- Arm a track → record a clip live → it loops automatically
- More flexible than Looper for multi-track live recording

**Best practice:** Set up 4–6 dedicated "live loop" tracks pre-armed and ready. During performance you just hit record on Push and play.

---

## 4. Sample Firing

**Drum Rack is your best friend:**
- Load one-shots, FX hits, vocal chops, risers, drops into Drum Rack
- Each pad on Push 2 fires a different sample
- Velocity sensitive — hit harder for louder/harder hits
- Chain multiple Drum Racks per genre/set section

**Hot tips:**
- Keep a dedicated "FX hits" rack: white noise risers, downlifters, crowd noise, sirens, stabs
- One-shot samples don't need to be looped — set clip to "trigger" mode, not loop
- Color-code your pad grid by type (drums = red, vocals = blue, FX = yellow)

---

## 5. The Mini Mixer — Where It Fits

Depends on what you've got:

**If it's a DJ mixer (e.g., Pioneer DJM-S3, Rane, Allen & Heath):**
- Route Ableton's main output into Channel 1
- Use the mixer EQ for live DJ-style cuts (kill the bass, sweep the filter)
- Crossfader if you want to blend between Ableton and external source (CDJ, phone, USB)
- Run a second source into Channel 2 for mixing in records/tracks on top of your live PA

**If it's a compact audio mixer (e.g., Behringer Xenyx, Mackie Mix):**
- Use it mainly for summing outputs and sending to PA/monitors
- Less useful for performance — the EQ and routing is limited
- Consider upgrading to a proper DJ mixer for more performance options

**Either way:** Make sure your audio interface is in the signal chain properly — Ableton → interface → mixer → PA.

---

## 6. Audio Interface (Critical If You Don't Have One)

If your mini mixer doesn't have a built-in audio interface, you need one between the Mac and the mixer. Without it you're running through the Mac's built-in audio which is garbage for live performance.

**Recommended:**
- **Focusrite Scarlett 2i2** (~$120) — simple, reliable, 2 outputs + headphone monitoring
- **Audient iD4 mk2** (~$130) — slightly better converters, same use case
- **Native Instruments Komplete Audio 6** (~$150) — 6 outputs, great if you need multiple send channels

Push 2 connects via USB — doesn't need the interface, goes straight to Mac.

---

## 7. Ableton Link — When to Use It

Ableton Link syncs tempo wirelessly between devices over WiFi. Use it when:
- Running a second Mac or iPad alongside Ableton
- Using iPad apps like Modstep, Koala Sampler, or GarageBand as a second instrument
- Syncing visuals (Resolume, TouchDesigner) to your music
- Jamming with another musician who also runs Ableton

For a solo live PA, Link is optional — you're the only clock source. But if you ever play with visual artists or other producers, it's essential.

## 9. What to Add Down the Road

**Priority 1 — Push 3 ($800–$1,500)**
Push 3 has a built-in audio interface AND can run standalone (no Mac required). Run your entire live PA from Push 3 alone. Major upgrade for live performance reliability — nothing crashes if your Mac freezes.

**Priority 2 — Better DJ Mixer (~$300–$600)**
Something with proper 3-band EQ kill switches, filter knob, and a clean crossfader. Allen & Heath Xone:23 or Pioneer DJM-S3 are solid. This opens up actual DJ mixing technique on top of your live PA.

**Priority 3 — MIDI Footswitch (~$60–$150)**
Leaves your hands free for Push while your feet control scene launches or looper record/stop. Keith McMillen SoftStep 2 or Behringer FCB1010 are popular.

**Priority 4 — iPad as Second Controller (~$400+)**
Run TouchAble Pro or Lemur on an iPad connected to Ableton via Ableton Link or OSC. Second screen of knobs and faders you can customize for your set. Great for a more hands-on visual display while Push handles the pads.

**Priority 5 — Hardware Synth (~$300–$700)**
Adding a hardware synth (Arturia MicroBrute, Roland JD-Xi, Korg Minilogue) gives you a physical instrument to play live. Route it into your mixer alongside Ableton. Changes the whole vibe — sounds rawer, more human.

---

## 10. Practice Workflow for a Live Set

1. Build your track library in Session View — at least 30–40 clips per set
2. Group clips into "scenes" that represent set energy levels (warm-up, build, peak, drop, outro)
3. Map your 8 macro knobs on Push before every show — filter, reverb, delay are essential
4. Practice "launching without looking" — you should be able to navigate your set in the dark
5. Always have a safety net: a pre-arranged backup set in Arrangement View for if things go sideways
6. Soundcheck: verify audio interface clock, buffer size (use 256 samples for live, not 128 — less CPU stress), and check latency compensation

## Live PA Best Practices — SOPs from Pro Performers

Based on how touring artists like Porter Robinson, deadmau5, Flume, RL Grime, Four Tet, and mashup/open-format live performers structure their rigs and workflows.

---

### 1. The Golden Rules

- **Never touch a mouse on stage.** Everything you need must be mapped to a physical control. If you're clicking, you've already lost.
- **Build redundancy into everything.** Two of anything critical — laptop backup, audio interface backup, the full set on a USB if Ableton dies.
- **The set should run without you if needed.** Follow Actions handle the transitions. You're adding to it, not holding it together.
- **Color everything.** In a dark venue at 2 AM, you navigate by color, not by reading.
- **Warp every clip before show day.** Never warp on stage.

---

### 2. Ableton Set Architecture — How the Pros Build It

**The Track Layout (left to right):**

```
[DRUMS] [PERC] [BASS] [CHORDS] [LEAD/MELODY] [VOCALS] [FX HITS] [LOOPS] [MASTER FX]
```

Each column is one sound type. Each row of clips = one "moment" or section of your set.

**Color coding by energy (non-negotiable):**
- 🟢 Green = intro / low energy / rebuild
- 🟡 Yellow = mid energy / verse / groove
- 🔴 Red = peak / drop / climax
- 🔵 Blue = breakdown / emotional moment
- ⚪ White = transitions / one-shots / stabs

You scan the grid by color, not by reading text. In the dark, under pressure, this saves you.

**Scene naming convention:**
```
01_INTRO
02_BUILD_1
03_DROP_A
04_BREAKDOWN
05_DROP_B_PEAK
06_OUTRO
```

Number them. If you ever want to jump sections, you know exactly where you're going.

---

### 3. Sample Organization — Where Everything Lives

**Folder structure (do this before you build anything):**

```
/Live Set Samples/
├── Drums/
│   ├── Kicks/
│   ├── Snares/
│   ├── Hi-Hats/
│   └── Full Loops/
├── Bass/
│   ├── Sub Bass/
│   ├── Synth Bass/
│   └── Bass Loops/
├── Chords + Pads/
├── Melodies + Leads/
├── Vocals/
│   ├── Full Phrases/
│   ├── Chops/
│   └── Ad-libs/
├── FX/
│   ├── Risers/
│   ├── Downlifters/
│   ├── Impacts/
│   ├── White Noise/
│   └── Crowd FX/
├── Stabs + Hits/
├── Mashup Elements/
│   ├── By Song Title/
│   └── Acapellas/
└── Stems/
    └── By Track Name/
```

**The key insight from top performers:** Everything is pre-labeled with **key and BPM** in the filename.
```
kick_heavy_01.wav → kick_heavy_01_128bpm.wav
vocal_chop_yeah_Gm.wav
riser_white_8bar_130bpm.wav
```

You never have to guess if something will fit. You see it at a glance.

---

### 4. The Drum Rack Setup (SP-404 or Ableton)

Every pro live PA has a dedicated pad bank for performance hits. Organize it like this:

**Pad layout (4x4 grid):**
```
[RISER 2bar] [RISER 4bar] [RISER 8bar] [IMPACT HIT]
[DOWNLIFT]   [WHITE NOISE] [CROWD YEA] [AIRHORN]
[VOCAL CHOP1][VOCAL CHOP2][VOCAL CHOP3][VOCAL STAB]
[KICK SHOT]  [SNARE SHOT] [CLAP SHOT] [808 BOOM]
```

Top row = FX and transitions (reach for these on every drop)
Second row = more FX hits
Third row = vocal one-shots for mashup moments
Bottom row = drum one-shots for fills and emphasis

**Color code the pads to match the grid colors above.** Red pads = big impacts. Blue pads = smooth/vocal. Green pads = transitions.

---

### 5. Macro Mapping — The Eight Knobs That Run Everything

Every Ableton Group Track gets 8 macros. Map them the same way on every track so muscle memory takes over:

| Knob | Function |
|---|---|
| 1 | Filter Cutoff |
| 2 | Filter Resonance |
| 3 | Reverb Send |
| 4 | Delay Send |
| 5 | Volume |
| 6 | Distortion / Drive |
| 7 | Pitch / Transpose |
| 8 | LFO Rate / Chop Speed |

Filter cutoff on Knob 1 is the DJ move — cut the bass out, sweep the filter up, bring it back. You'll use this constantly.

---

### 6. Live Loop Workflow (Looping on the Fly)

Set up 4–6 "capture tracks" — always armed, always ready.

**How pros use them:**
1. Pre-set loop length (4 bars, 8 bars) before the moment
2. Hit record → play something live (on Push, on a synth, sing into a mic)
3. Loop fires automatically in sync with the master clock
4. Stack layers on top — bass loop, then melody loop, then vocal loop
5. Clear them one by one for a dramatic strip-down breakdown

**Key:** Set Follow Actions on loop clips to "loop again" indefinitely. They keep going until you manually stop them. No babysitting.

---

### 7. Mashup-Specific Workflow (Your Lane)

For open-format mashup live PA (Girl Talk, Crooklyn Clan style), the workflow is different from pure electronic PA.

**How it works:**
- Build "blocks" not full songs. Each block is 16–32 bars of a mashup moment.
- Stack the acapella of Song A over the instrumental of Song B — pre-built, pre-warped, in the clip grid.
- Launch blocks in real time. Transition with an FX hit or riser between them.
- Keep 3–4 blocks at the same energy level so you can extend a peak if the crowd is going nuts.

**The secret weapon:** Stems. Strip your tracks down to stems (drums, bass, top) instead of full mixes. Lets you swap drums from one song under the vocals of another live — real-time remixing nobody else in the room can do.

**Stem tools:** Moises, Spleeter, or the stems feature in Rekordbox/Virtual DJ.
