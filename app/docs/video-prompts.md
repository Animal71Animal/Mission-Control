## Generation Tips

- **Kling AI:** Go to app.klingai.com → Image to Video → upload reference photo → paste prompt → set duration to 5–10 seconds → generate. Run 2–3 variations and pick the best.
- **Runway Gen-3:** Similar — upload image, paste prompt, generate.
- **Settings:** Use highest quality mode available. For Kling: "Standard" or "Pro" mode.
- **Lip sync:** After generating the video, run through **HeyGen** or **Sync.so** to add real lip-sync to the spoken line. This makes it look like they're actually talking.
- **Music bed:** Add a 5-second clip of each artist's future track under the video when available.
