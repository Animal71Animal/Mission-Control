## Known Plugins to Install

### ✅ Priority 1 — Install These First

- [ ] **Xfer Serum** — download from xferrecords.com, run installer, AU/VST auto-installs
  - After install: move presets to `~/Music/ANIMAL/08_Samples/Serum-Presets/`
  - Point Serum's preset folder to that location inside the plugin

- [ ] **Rob Papen plugins** — download from robpapen.com, run installers
  - Likely includes: Blue-II, SubBoomBass, Predator, Punch, Blade — install all at once
  - After install: export/save presets to `~/Music/ANIMAL/08_Samples/Rob-Papen-Presets/`

- [ ] **Splice** — download app from splice.com
  - In Splice settings: set download folder to `~/Music/ANIMAL/08_Samples/Splice/`
  - This keeps all Splice samples in one organized place

### ✅ Loopmasters / Loopcloud

- [ ] Download Loopcloud app from loopcloud.com — installs desktop app + VST/AU plugin together
- [ ] In Loopcloud settings: set local download folder to `~/Music/ANIMAL/08_Samples/Loopmasters/`
- [ ] After install: open Ableton → rescan plugins → Loopcloud plugin will appear in browser
- [ ] Add Loopcloud as a plugin on any track to browse + preview samples in-session at your tempo
- [ ] Workflow: search sample in Loopcloud → preview in key → drag directly onto Ableton track

### 🔮 Recommended Additions (When Budget Allows)

- [ ] **Ableton Live Suite upgrade** (~$250 upgrade from Standard)
  - Unlocks Max for Live — needed for advanced live performance tools
  - Worth it for the live PA build

- [ ] **iZotope RX** — industry standard for audio repair and vocal cleaning
- [ ] **FabFilter Pro-Q 3** — best EQ plugin available, essential for mastering
- [ ] **Waves Gold bundle** — if you have existing licenses, reauthorize these
- [ ] **Native Instruments Komplete** — massive instrument library, great for production

## Ableton Setup Steps (Do This After Installing Plugins)

1. Open Ableton → Preferences → Plugins
2. Set VST2 folder: `~/Library/Audio/Plug-Ins/VST/`
3. Set VST3 folder: `~/Library/Audio/Plug-Ins/VST3/`
4. Enable AU plugins: check "Use Audio Units"
5. Click "Rescan" — Ableton will find everything

6. Preferences → Library
7. Set User Library to: `~/Music/Ableton/User Library/`

8. In Ableton sidebar → Add folder → `~/Music/ANIMAL/08_Samples/`
   - This makes your entire sample library browsable from inside Ableton

9. In Splice app settings → Change download folder to `~/Music/ANIMAL/08_Samples/Splice/`
