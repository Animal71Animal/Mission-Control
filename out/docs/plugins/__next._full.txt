<h2>Ableton Setup Steps (Do This After Installing Plugins)</h2>
<ol>
<li><p>Open Ableton → Preferences → Plugins</p>
</li>
<li><p>Set VST2 folder: <code>~/Library/Audio/Plug-Ins/VST/</code></p>
</li>
<li><p>Set VST3 folder: <code>~/Library/Audio/Plug-Ins/VST3/</code></p>
</li>
<li><p>Enable AU plugins: check &quot;Use Audio Units&quot;</p>
</li>
<li><p>Click &quot;Rescan&quot; — Ableton will find everything</p>
</li>
<li><p>Preferences → Library</p>
</li>
<li><p>Set User Library to: <code>~/Music/Ableton/User Library/</code></p>
</li>
<li><p>In Ableton sidebar → Add folder → <code>~/Music/ANIMAL/08_Samples/</code></p>
<ul>
<li>This makes your entire sample library browsable from inside Ableton</li>
</ul>
</li>
<li><p>In Splice app settings → Change download folder to <code>~/Music/ANIMAL/08_Samples/Splice/</code></p>
</li>
</ol>
